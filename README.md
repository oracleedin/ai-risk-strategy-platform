# AI 风控策略配置平台

AI Risk Strategy Configuration Platform - 面向交易平台风控/治理/策略团队的产品经理作品集 Demo

## 📖 项目简介

AI 风控策略配置平台是一个面向交易平台风控/治理/策略团队的产品经理作品集 Demo。系统模拟恶意退款、商家刷单、补贴薅羊毛、商品违规等风险场景，提供风险案件审核、规则策略配置、阈值模拟和策略效果看板。

项目重点展示风控策略产品中**规则配置**、**AI 风险解释**、**人工复核**、**误杀/漏放平衡**和**数据闭环设计能力**。

> ⚠️ **Mock 数据声明**：当前 Demo 使用模拟风险案件、Mock 风控规则和前端计算指标，不含真实平台用户数据。

## 🎯 产品背景

交易平台中的风险行为越来越复杂，单纯依赖人工审核效率低，单纯依赖 AI 模型又容易黑盒化。

**风控策略不是越严越好**：
- 规则太松会漏放真实风险
- 规则太严会误伤正常用户和商家
- 增加审核成本并影响业务体验

本平台提供从风险识别、解释、审核、策略配置到效果复盘的完整闭环。

## ✨ 核心功能

| 功能模块 | 说明 |
|---------|------|
| **风险案件审核** | 三栏布局展示案件列表、详情和审核操作，支持按场景筛选和 AI 风险解释 |
| **规则策略配置** | 可视化配置风控规则条件、阈值、逻辑关系、风险等级和处理动作 |
| **阈值模拟器** | 动态模拟不同阈值下的拦截率、误杀率、漏放率和人工审核量 |
| **策略效果看板** | 追踪策略上线后的核心指标，支持 v1.8 / v2.1 版本对比 |

## 💡 项目亮点

1. **完整 B 端后台信息架构**：Landing Page + 多页面后台系统，适合面试现场演示
2. **规则引擎思维**：展示风控规则的条件配置、阈值调整、逻辑关系设计
3. **AI 风险解释**：每条风险案件都有 AI 生成的解释，说明命中原因和处理建议
4. **误杀/漏放平衡**：通过阈值模拟器直观展示不同阈值对各项指标的影响
5. **策略效果闭环**：看板展示策略上线后的核心指标，支持版本对比

## 🎨 作品集展示价值

本项目可作为产品经理作品集展示，体现以下能力：

- **风控策略产品能力**：理解风控不是越严越好，需要平衡拦截率、误杀率、漏放率和审核成本

- **数据指标设计**：设计北极星指标和一级指标，建立策略效果评估体系
- **B 端产品设计**：多页面信息架构、卡片式布局、清晰的视觉层级
